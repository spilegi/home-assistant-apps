## LAN application access

When running or developing this application, make it reachable from other devices on the local network. Bind the server to 0.0.0.0 (or an equivalent all-interface address), not only localhost or 127.0.0.1. Preserve appropriate authentication and do not expose secrets. When development or production links have been configured in Codex Web, use and report the appropriate link. If none is configured, tell the user the host/IP and port being used.
